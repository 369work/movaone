== Description ==

Movaone is a mobile-first WordPress dark theme with a distinctive two-column layout:
a fixed left "aside" panel and a scrollable right content area.

Since the site is designed around the mobile viewport, pages load fast on all devices,
which helps reduce bounce rates and keeps visitors engaged.

On desktop (1024px+), the left panel stays fixed while the right panel scrolls — a layout
that feels native on smartphones and elegant on larger screens.

/*== Installation ==*/
1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.


/*== Frequently Asked Questions ==*/

= How do I customize the left panel content? =
Go to Pages in your WordPress admin and edit the page with the slug "aside".
This page content is displayed in the fixed left panel on desktop view.

= How do I change the header color? =
Go to Appearance > Customize > Movaone Features and use the color pickers
for "Header Background color (gradation 2color select)".

= How do I set up the CTA button? =
Go to Appearance > Customize > Movaone Features and fill in the CTA Button Text
and CTA Button Link fields.
