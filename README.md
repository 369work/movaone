## About Movaone

Movaone is a mobile-first WordPress dark theme with a distinctive two-column layout:
a **fixed left "aside" panel** and a **scrollable right content area**.

Since the site is designed around the mobile viewport, pages load fast on all devices,
which helps reduce bounce rates and keeps visitors engaged.

On desktop (1024px+), the left panel stays fixed while the right panel scrolls —
a layout that feels native on smartphones and elegant on larger screens.

---

## Theme Features

- **Mobile-First** layout optimized for smartphones
- **Unique two-column design**: fixed aside panel + scrollable content area
- **Dark theme** with customizable header gradient (2-color)
- **CTA Button** in header — text and link configurable via Customizer
- Custom Header, Logo, and Background support
- SEO friendly
- Accessibility ready (skip link, ARIA attributes, keyboard navigation)
- Translation ready (`ja.po` / `ja.mo` included)
- WordPress Theme Customizer support
- 3-level drop-down menu
- Threaded Comments & Gravatar
- Related Posts
- Featured Images & Post Formats support

---

## Customization

### Left Panel (Aside)
Edit the WordPress page with the slug `aside`.
Its content is displayed in the fixed left panel on desktop.

### Header Color
Go to **Appearance > Customize > Movaone Features** and use the two gradient color pickers.

### CTA Button
Set the button text and link in **Appearance > Customize > Movaone Features**.

---

## Installation

1. In your admin panel, go to **Appearance > Themes** and click **Add New**.
2. Click **Upload Theme**, choose the `.zip` file, and click **Install Now**.
3. Click **Activate** to start using the theme.
